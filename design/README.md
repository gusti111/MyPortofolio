# Design handoff assets

The `/public/assets` SVG files are original editable vector assets:
- `favicon.svg`
- `og-cover.svg`
- `project-*.svg` project cover illustrations

They can be opened and edited in Figma, Illustrator, Inkscape, or a code editor.

The React UI is the implemented high-fidelity design reference. The component system, color tokens, responsive rules, interaction states, and layout specifications are in `src/styles.css`, `src/App.tsx`, and `DESIGN-SYSTEM.md`.

This delivery is a code-first design handoff rather than a native `.fig` file. No Figma document has been created or modified.

# Design System — Gusty Faqikh Portfolio

## Direction
Minimalist Professional × Premium Dark. Recruiter-first, evidence-led, responsive.

## Foundations
- Typeface: DM Sans for UI/body; Space Grotesk for display headings.
- Accent: blue (`#2563EB` light, `#60A5FA` dark).
- Light: background `#F7F8FA`, surface `#FFFFFF`, text `#172033`.
- Dark: background `#0B1220`, surface `#111C2E`, text `#F3F6FC`.
- Spacing: 4px base scale.
- Radius: 8–16px.
- Content width: 1160px maximum.
- Grid: 12-column desktop intent; responsive 2-column project cards and 1-column mobile.

## Components
Header, responsive navigation, brand monogram, buttons, project cards, tags, section headings, skill groups, timeline, education card, certificate source card, CV paper, contact cards, command palette, empty state, status and notices.

## Interactions
Theme toggle (light/dark/system through persisted preference), language toggle (ID/EN), project search and category filter, command palette (`Ctrl/Cmd + K`), certificate source link, print/save PDF, copy email, route navigation.

## Accessibility
Semantic landmarks, visible keyboard focus, labelled inputs, keyboard-operable controls, `aria-live` copy feedback, reduced-motion support, descriptive image alternatives. Manual screen-reader and contrast verification remains a release task.

## Breakpoints
600px, 850px, 1100px. Content behavior is fluid between breakpoints.
